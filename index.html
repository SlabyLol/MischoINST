Mischo Remote Desktop

Control your Windows or Linux machine remotely through a browser with Mischo.

Download & Installation

Windows

  1. Download the installer: installmischo.bat
  2. Run the installer. It will download the Python script, install packages, build the agent binary, set autostart, and launch it.

Linux / Debian / Raspberry Pi OS

  1. Download the installer: installer.sh
  2. Run the installer: 
    bash installer.sh

Connecting to Mischo

Open your browser and enter the IP of the device running Mischo Agent with port 8080:

http://100.125.128.6:8080
