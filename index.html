Mischo Remote Desktop Installation Guide

Control your Windows or Linux machine remotely through a browser with Mischo.

Download & Installation

Windows

  1. Download the installer: Download Windows Installer
  2. Run the installer. It will:
    • Download the Python agent script
    • Install required Python packages
    • Build the Mischo Agent binary
    • Set it to start automatically
    • Launch the agent immediately

Linux / Debian / Raspberry Pi OS

  1. Download the installer: Download Linux Installer
  2. Run the installer in terminal: 
    bash installer.sh
    The installer will do the same steps as Windows: download agent, install packages, build binary, setup autostart, and launch the agent.

Connecting to Mischo

After installation, open your browser and enter the IP of the device running Mischo Agent with port 8080:

http://YOUR-IP:8080

Replace YOUR-IP with the actual IP of your machine.

Browser Remote Control

You can also use the web frontend to control the remote machine:

Open your browser → enter the agent IP → view screen & control mouse/keyboard
